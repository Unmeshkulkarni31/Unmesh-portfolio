# Unmesh Kulkarni — Portfolio

Static site: just HTML, CSS and JS. No build step.

## Run
Open `index.html` in a browser (or use VS Code "Live Server").

## Edit
- Text/projects/links: `index.html` (search for `TODO` to find placeholders like repo and live-demo links)
- Colors/fonts: top of `style.css` (`:root` tokens)
- Typing lines in the hero: `lines` array in `script.js`
- Resume: replace `assets/Unmesh_Resume.pdf` (keep the file name)

## Contact form (FormSubmit)
Messages go to unmeshkulkarni205@gmail.com. The first time anyone submits the form
from your LIVE site, FormSubmit emails you an activation link. Click it once, and after that
every message arrives in your inbox. Test it yourself once after deploying.
Note: it will not work from a local file:// page; use a deployed site or Live Server.

## Deploy free
Netlify Drop (drag the folder), Vercel, or GitHub Pages.
